Case Study · GAMOMAT · 2026

Marketing Hub: eine Schaltzentrale statt vieler Einzeltools

GAMOMAT bringt rund zwei neue Spiele pro Monat auf den Markt. Für jedes Release braucht das Team Assets, Texte, Partnerkommunikation, Newsletter und Dokumentation, verteilt auf viele Tools. Statt ein weiteres Standard-Tool einzukaufen, habe ich die echten Abläufe des Teams aufgenommen und daraus ein eigenes, KI-gestütztes System gebaut.

  • Bündelt die wiederkehrenden Marketing-Abläufe in einer Oberfläche
  • Verbindet bestehende Systeme über API- und Webhook-Integrationen
  • Nutzt KI-Workflows für Text, Bild, Video und Recherche
  • Standardisiert Abläufe, sodass Ergebnisse gleich gut sind, egal wer sie erledigt
  • Claude Code
  • n8n
  • Supabase
  • AWS S3
